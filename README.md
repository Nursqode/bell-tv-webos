# Bell.TV — IPTV-плеер для LG webOS

<p align="center">
  <img src="assets/icon.png" width="160" alt="Bell.TV">
</p>

<p align="center">
  Небольшой, быстрый и аккуратный IPTV-плеер для телевизоров LG на webOS.
  Список каналов, избранное, недавние, полноэкранный HLS-плеер и автоматическое
  обновление ссылок на потоки.
</p>

> Автор: **Nursqode**. Проект неофициальный и не связан с LG Electronics, webOS
> или правообладателями транслируемых каналов.

## Возможности

- **Четыре источника каналов** (вшиты в сборку):
  - **BeeTV** — 227 каналов;
  - **Россия** — 507 каналов (iptv-org, 42 жанровые группы);
  - **Казахстан** — 49 каналов (iptv-org, 11 групп);
  - **Узбекистан** — 34 канала (iptv-org, 11 групп), включая **Qaraqalpaqstan**.
- **★ Избранное** — удержание кнопки OK на канале добавляет/убирает его из избранного
  (звёздочка в списке, тост-подтверждение).
- **Последние** — автоматически хранит 5 последних просмотренных каналов (без дублей).
- **Фирменный шрифт Manrope** вшит в приложение (латиница + кириллица): одинаковый
  вид на любом телевизоре, без скачивания шрифтов из сети.
- **OLED-чёрная тема** с фирменным красным акцентом Bell (#FF3B30): фокус, активный
  источник и звёздочка избранного подсвечиваются красным.
- **Тонкий индикатор прокрутки** справа — видно, где ты находишься в списке из сотен каналов.
- **Звёздочка избранного** — в правом верхнем углу карточки канала.
- **Тонкая красная дуга** вместо спиннера при загрузке потока.
- **Быстрая навигация**:
  - `←` / `→` — переключение источника;
  - `↑` / `↓` — по одному каналу;
  - `CH+` / `CH−` и `PageUp` / `PageDown` — постранично;
  - **колесо Magic Remote** — по одному каналу за щелчок;
  - `OK` — смотреть, удержание `OK` — избранное, `Back` — назад/выход.
- **Полноэкранный плеер** с подгрузкой потока, названием канала внизу справа и
  индикатором реального разрешения потока внизу слева.
- **Автообновление ссылок**: раз в сутки в фоне приложение подтягивает свежие
  плейлисты [Romaxa55/world_ip_tv](https://github.com/Romaxa55/world_ip_tv)
  (запасной вариант — iptv-org) и заменяет устаревшие ссылки на потоки. Список
  каналов, их порядок и названия не меняются.
- **Мгновенный запуск**: список показывается сразу (из кеша/сборки), обновление
  ссылок идёт в фоне с таймаутом; результаты кешируются на 24 часа.
- **Стабильные избранное и «Последние»**: хранятся по ключу `источник|название`,
  поэтому обновление ссылок не «ломает» закладки.
- Логотипы каналов подгружаются по мере появления, битые запоминаются и больше
  не мигают при прокрутке.
- Тёмный минималистичный интерфейс, крупные карточки, работа с пульта без
  лишних нажатий. Иконка приложения и шапка — в фирменном стиле **Bell.TV**
  (надпись `Bell` + красное `.TV`).

## Совместимость

| Параметр | Значение |
|---|---|
| Проверено на | LG **WEB-43S**, webOS **23** (major 8), прошивка **8.4.9-49** |
| Минимально | webOS **6.0** (Chromium 87+) |
| Возможно, но не тестировалось | webOS 4.x/5.x (Chromium 68+), webOS 22–26 |
| Root | для самого приложения **не нужен** (это обычный web-app) |
| Интернет | обязателен для воспроизведения потоков |

Приложение не содержит нативных библиотек и работает на встроенном в webOS
Chromium. HLS воспроизводится штатным плеером; при его отсутствии подключается
`hls.js` (вшит в пакет).

## Установка

### Вариант 1. Рутованный ТВ + Homebrew Channel (рекомендуется)

1. Скачайте `.ipk` из раздела **[Releases](../../releases)**.
2. Скопируйте пакет на телевизор по SSH:
   ```sh
   scp tv.iptv.web_1.6.0_all.ipk root@192.168.1.50:/tmp/
   ```
3. Установите через сервис установки webOS:
   ```sh
   ssh root@192.168.1.50 \
     "luna-send -n 1 -i 'luna://com.webos.appInstallService/dev/install' \
      '{\"id\":\"com.ares.defaultName\",\"ipkUrl\":\"/tmp/tv.iptv.web_1.6.0_all.ipk\",\"subscribe\":true}'"
   ```
4. Приложение появится в списке приложений (Home → Apps) под именем **Bell.TV**.

> SSH на рутованном ТВ обычно уже включён Homebrew Channel; до настройки ключей
> пароль `alpine`.

### Вариант 2. Developer Mode + webOS CLI / Dev Manager

1. Установите на ТВ приложение **Developer Mode** из LG Content Store и включите его.
2. На компьютере установите CLI:
   ```sh
   npm install -g @webos-tools/cli
   ares-setup-device            # добавьте ТВ (host, порт 9922, пользователь prisoner)
   ares-install --device <имя> tv.iptv.web_1.6.0_all.ipk
   ```
3. Подойдёт и [webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop):
   добавить устройство → Apps → перетащить `.ipk`.

### Запуск

Home → **Apps** → **Bell.TV**. Иконку можно вынести на главный экран или
использовать как основной экран через сторонние лаунчеры webOS.

### Удаление

Через Homebrew Channel (Uninstall) или по SSH:
```sh
ssh root@192.168.1.50 \
  "luna-send -n 1 -f 'luna://com.webos.appInstallService/dev/remove' '{\"id\":\"tv.iptv.web\"}'"
```

## Сборка из исходников

Требования: Python 3.8+ и Pillow (для иконок).

```sh
git clone https://github.com/Nursqode/bell-tv-webos.git
cd bell-tv-webos
python3 -m pip install pillow
python3 tools/fetch_playlists.py    # скачивает публичные плейлисты в ./data
python3 build_iptv_app.py           # собирает dist/tv.iptv.web_<версия>_all.ipk
```

Готовый пакет появляется в `dist/` — его устанавливают способом из раздела выше.

## Структура репозитория

```
src/               исходники web-приложения (index.html, app.js, style.css)
tools/             скрипт загрузки плейлистов
assets/            иконка приложения
data/              сюда складываются плейлисты (не коммитятся)
build_iptv_app.py  сборка .ipk
build_webapp_ipk.py упаковка ar/tar для .ipk
dist/              готовые .ipk (не коммитится)
```

## Источники и автообновление

| Источник | Откуда | Обновление |
|---|---|---|
| BeeTV | [gitea.com/Monoloshka/BeeTV](https://gitea.com/Monoloshka/BeeTV) | при пересборке |
| Россия / Казахстан / Узбекистан | [iptv-org/iptv](https://github.com/iptv-org/iptv) | при пересборке |
| Актуальные ссылки на потоки | [Romaxa55/world_ip_tv](https://github.com/Romaxa55/world_ip_tv) (fallback — iptv-org) | приложением, раз в 24 часа |

Приложение хранит только список каналов и ссылки на публичные потоки. Сами
каналы транслируются сторонними серверами, автор не контролирует их доступность
и легальность. Часть каналов может быть недоступна в вашем регионе или со
временем перестать работать.

## Ограничения

- Нет EPG (телепрограммы) и нет видеотеки — это live-IPTV-плеер, а не онлайн-кинотеатр.
- Некоторые потоки могут не воспроизводиться из-за кодека, гео-блокировки или DRM.
- Публичные плейлисты неофициальны: каналы появляются, пропадают и меняют адреса.
- Интерфейс на русском языке.
